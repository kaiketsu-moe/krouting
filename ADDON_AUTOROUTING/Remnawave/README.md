### Интеграция с Remnawave

Для поддержки автороутингов в Remnawave используйте утилиту автообновления через API:
https://github.com/lifeindarkside/Remnawave-Routing-update

Шаблон роутинга для вставки доступен в файле:
`MIHOMO/template_remnawave.yaml`
или по прямой ссылке:
`https://raw.githubusercontent.com/kaiketsu-moe/krouting/main/MIHOMO/template_remnawave.yaml`
