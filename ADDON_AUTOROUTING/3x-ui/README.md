### Автороутинг для 3x-ui

Для поддержки автороутингов в 3x-ui используйте fork с поддержкой внешних правил:
https://github.com/hydraponique/3x-ui

В настройках укажите ссылки на ваши `geoip.dat` и `geosite.dat`:
- **GeoIP URL**: `https://github.com/kaiketsu-moe/krouting/releases/latest/download/geoip.dat`
- **GeoSite URL**: `https://github.com/kaiketsu-moe/krouting/releases/latest/download/geosite.dat`
